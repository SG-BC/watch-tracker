# Watch Tracker
An advanced sync and tracking addon for Kodi.

## Installation

### Manual

1. Download the addon zip file.
2. In Kodi, go to Add-ons -> Install from zip file and select the zip.

If Kodi refuses, open Settings -> System -> Add-ons and switch Unknown sources on. It also helps to set Update official add-ons from to Any repository, so updates from third-party repositories are accepted. (Exact labels differ a little between Kodi versions and skins.)

### Automatic (repository)

1. In Kodi's File manager, choose Add source and enter `https://sg-bc.github.io/repo.sg-bc`.
2. Go to Add-ons -> Install from zip file, pick that source and install the repository zip you find there.
3. Install Watch Tracker from Install from repository. Kodi will then keep it updated.
